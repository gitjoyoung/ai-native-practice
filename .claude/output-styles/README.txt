무엇인가요?
- Claude가 "어떤 태도와 형식으로 대답할지"를 바꾸는 설정이에요.
  같은 선생님이라도 초등학생 반과 대학원 수업에서 말투가 다른 것과 같아요.
  예) 설명을 많이 하는 교육 모드, 결론만 짧게 말하는 모드

어떻게 쓰나요?
- .md 파일 하나 = 스타일 하나예요. 예) concise.md

    ---
    name: 간결
    description: 결론만 짧게 답한다
    ---
    항상 세 문장 이내로 답한다. 코드 설명은 생략한다.

- Claude Code에서 `/config`를 열고 Output style 항목에서 고르면 돼요.
- CLAUDE.md는 "무엇을 지킬지", 출력 스타일은 "어떻게 말할지"를 정해요.
