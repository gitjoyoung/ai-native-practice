무엇인가요?
- 자주 하는 지시를 저장해 두고 `/이름`으로 부르는 곳이에요.
  휴대폰의 "자주 쓰는 문구"와 비슷해요.

어떻게 쓰나요?
- .md 파일 하나 = 명령 하나예요. 파일 이름이 명령 이름이 돼요.
  예) review.md → /review
- 파일 안에는 Claude에게 할 말을 그대로 적어요.
- $ARGUMENTS라고 쓰면 명령 뒤에 친 글자가 그 자리에 들어가요.
  예) "$ARGUMENTS 파일을 리뷰해 줘" 라고 저장하고 `/review app.ts` 실행

참고
- 지금은 skills 폴더가 이 기능을 포함해요. 스킬도 `/이름`으로 부를 수 있어요.
- 새로 만든다면 skills를 쓰세요. 이 폴더는 예전 방식이고 호환용으로만 남아 있어요.
