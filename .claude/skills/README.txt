[skills 폴더 — 스킬(작업 매뉴얼)]

무엇인가요?
- 특정 작업의 "요리 레시피"를 모아 두는 곳이에요.
  예) 배포 절차, PR 작성 양식, 우리 팀 API 만드는 법
- 평소에는 Claude가 레시피의 제목과 한 줄 설명만 기억해요.
  관련된 일이 생기면 그때 본문을 펼쳐 읽어요.
  그래서 많이 넣어 둬도 대화가 무거워지지 않아요.

어떻게 쓰나요?
- 폴더 하나 = 스킬 하나예요. 폴더 안에 SKILL.md 파일이 꼭 있어야 해요.

    skills/
    └── deploy/
        ├── SKILL.md        ← 필수
        ├── checklist.md    ← 선택: 참고 자료
        └── run.sh          ← 선택: 같이 쓸 스크립트

- SKILL.md 맨 위에 이름표를 붙여요.

    ---
    name: deploy
    description: 배포하거나 릴리스할 때 사용
    ---
    (여기부터 단계별 작업 지시문)

- Claude가 알아서 꺼내 쓰기도 하고, `/deploy`처럼 직접 부를 수도 있어요.
