[rules 폴더 — 주제별 규칙]

무엇인가요?
- CLAUDE.md가 너무 길어질 때 규칙을 주제별 파일로 나눠 두는 곳이에요.
  두꺼운 사규 한 권을 "보안 편", "테스트 편"처럼 얇은 책자로 나누는 것과 같아요.

어떻게 쓰나요?
- .md 파일 하나 = 규칙 묶음 하나예요. 예) testing.md, security.md
- 그냥 쓰면 CLAUDE.md처럼 대화를 시작할 때 항상 읽혀요.
- 맨 위에 paths를 적으면 그 경로의 파일을 다룰 때만 읽혀요.

    ---
    paths:
      - "src/api/**/*.ts"
    ---
    API 파일은 항상 입력값을 검사한다.

  이렇게 하면 API 파일을 고칠 때만 이 규칙이 떠올라서 대화가 가벼워져요.
