[.claude 폴더 안내서]

이 폴더는 이 프로젝트 전용 "Claude 설정 서랍"이에요.
JSON 파일에는 주석(설명 글)을 넣을 수 없어서, 여기에 대신 적어 둬요.

──────────────────────────────────────
settings.json  (팀 공용 · git에 올림)
──────────────────────────────────────
- 팀 모두에게 적용되는 Claude 규칙표예요.
- 주로 넣는 것:
  · permissions : 허락 없이 해도 되는 일(allow), 물어보고 할 일(ask), 절대 안 되는 일(deny)
                  예) "allow": ["Bash(npm run test:*)"], "deny": ["Read(./.env)"]
  · hooks       : 정해진 순간에 자동으로 실행할 명령
                  예) 파일을 고칠 때마다 포맷터 실행
  · env         : Claude가 쓸 환경변수
- 맨 위의 "$schema" 줄은 편집기 자동완성용이에요. 지우지 마세요.

──────────────────────────────────────
settings.local.json  (나만 · git에 안 올림)
──────────────────────────────────────
- settings.json과 쓰는 법이 같은데 내 PC에만 적용돼요.
- Claude가 권한을 물을 때 "항상 허용"을 고르면 여기에 자동으로 기록돼요.
- 두 파일에 같은 항목이 있으면 이 파일이 이겨요.
  우선순위: settings.local.json > settings.json > ~/.claude/settings.json(전역)

──────────────────────────────────────
../.mcp.json  (프로젝트 폴더 맨 위에 있음 · git에 올림)
──────────────────────────────────────
- Claude에 꽂을 외부 도구(MCP 서버) 목록이에요. 예) DB, 브라우저, 사내 API
  노트북에 USB 장치를 꽂는 것과 비슷해요.
- Claude Code가 이 위치에서 찾기 때문에 .claude 안이 아니라 맨 위에 있어요.
- 직접 쓰기보다 `claude mcp add --scope project <이름> ...` 명령으로 추가하는 게 편해요.
- 처음 쓸 때 "이 서버를 믿을까요?" 하고 한 번 물어봐요.

──────────────────────────────────────
하위 폴더
──────────────────────────────────────
각 폴더에 있는 README.txt를 보세요.
  agents/         한 가지 일만 맡는 전문 도우미
  skills/         필요할 때 꺼내 쓰는 작업 매뉴얼
  commands/       /이름 으로 부르는 단축 명령 (옛 방식, 지금은 skills 권장)
  rules/          주제별·경로별로 나눈 규칙
  hooks/          자동 실행 스크립트 보관함
  output-styles/  Claude의 말투와 답변 형식

※ 설명 파일을 .md가 아니라 .txt로 만든 이유
  agents, commands, rules, output-styles 폴더에서는 Claude가 .md 파일을 전부 자기 설정으로 읽어 가요.
  README.md로 만들면 "README"라는 에이전트나 명령이 잘못 생겨요. .txt는 무시돼요.
